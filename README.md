# RedBus Business Analytics Dashboard
Developed a 4-page interactive Power BI dashboard using 100,000+ RedBus booking records to analyze revenue, routes, operator performance, and customer behavior. 
Performed data cleaning with Power Query, created DAX measures for KPIs, and designed interactive visualizations with slicers, drill-downs, and cross-filtering.

Key insights included top revenue-generating routes, operator performance comparison, occupancy and cancellation analysis, customer age and gender segmentation, and payment method contribution to revenue.

Tools: Power BI, Power Query, DAX, Data Modeling
